CynusLink

ESP32-C3 SuperMini Web Installer

Connect your ESP32-C3 SuperMini via USB and install CynusLink directly from a supported browser.

Installation

  1. Connect the ESP32-C3 SuperMini to your computer via USB.
  2. Use Google Chrome or Microsoft Edge.
  3. Click Connect above.
  4. Select the ESP32-C3 serial device.
  5. Confirm the installation and wait until flashing is complete.
  6. Disconnect and reconnect USB power.

Target: ESP32-C3 SuperMini
